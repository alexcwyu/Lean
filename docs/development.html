Build and run the .NET engine

The actual application is the C#/.NET solution, with CPython embedded for Python algorithms. The uv project manages the embedded interpreter's packages; it is not a replacement engine or a separately importable Python distribution. The branch selects managed CPython 3.11 because the current QuantConnect.pythonnet embedding binary fails on 3.15. The latest compatible scientific core and optional package cohorts are declared in pyproject.toml and recorded in uv.lock.

uv sync --locked --group third-party
uv run dotnet build QuantConnect.Lean.sln --configuration Release

For embedded tests, set PYTHONNET_PYDLL to the uv-managed interpreter's libpython3.11.dylib on macOS, and PYTHONPATH to .venv/lib/python3.11/site-packages. Run the existing NUnit suite through the genuine .NET test project, not a synthetic pytest wrapper:

uv run --no-sync dotnet test Tests/QuantConnect.Tests.csproj \
  --configuration Release --no-build \
  --logger 'trx;LogFileName=existing-suite.trx' \
  --results-directory TestResults/ayu

The Python package fixture restores a real Python executable for subprocess workers. On macOS, its Torch, XGBoost and scikit-learn native dependencies require one compatible OpenMP loader: the verified run sets DYLD_LIBRARY_PATH=/opt/homebrew/opt/libomp/lib. The existing OR-Tools solver workflow runs in an owned managed-Python subprocess, preserving its original solver assertions while isolating conflicting native protobuf and HiGHS libraries from TensorFlow/CVXPY in the embedded host. The helper captures both streams, asserts the genuine exit status and terminates its owned process tree on timeout; the scientific libraries retain their current compatible versions. Package import success alone is not a functional workflow check. The Python3.11-compatible PyStan wheel embeds an Intel-only Stan compiler; the independently locked current Python3.14 PyStan/httpstan cohort provides a genuine universal ARM compiler. Several other optional libraries require mutually incompatible NumPy/Pandas cohorts. See validation for exact results and prerequisites.
